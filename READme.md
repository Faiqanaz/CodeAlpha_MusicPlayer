# Modern Music Player Application

A sleek, responsive music player application built with HTML5, modern CSS3 (Glassmorphism design), and Vanilla JavaScript.

## Features
- **Interactive Playlist:** Slide-up playlist drawer to select tracks directly.
- **Autoplay Control:** Toggle automatic track progression.
- **Audio Controls:** Full play/pause, next, previous, and volume adjustments.
- **Seekable Progress Bar:** Click anywhere on the progress bar to jump to specific timestamps.
- **Responsive UI:** Smooth glowing visuals and vinyl spinning animation during playback.

## Tech Stack
- HTML5 / CSS3 (CSS Variables, Flexbox, Animations)
- JavaScript (DOM Manipulation, Audio API, Event Listeners)
